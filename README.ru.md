## Что это?

Linuxify — небольшое приложение в трее и современная панель настроек, которые объединяют набор отличных open-source инструментов:

- [GlazeWM](https://github.com/glzr-io/glazewm) — тайловый оконный менеджер
- [Zebar](https://github.com/glzr-io/zebar) — верхняя панель состояния
- [Windhawk](https://windhawk.net) — моды панели задач
- тема Catppuccin Mocha для Windows Terminal, приглашение [Starship](https://starship.rs) и баннер [fastfetch](https://github.com/fastfetch-cli/fastfetch)

Linuxify сохраняет копии конфигурационных файлов, которые заменяет, а *режим Linux* можно выключить в любой момент и вернуть обычный Windows.

## Возможности

- **Режим Linux в один клик** — клик по значку в трее (или **Ctrl+Alt+L**) запускает/останавливает GlazeWM + Zebar и применяет/убирает тему терминала.
- **Современная панель** — окно в стиле Windows 11 с акриловым стеклом, тёмным заголовком, боковой навигацией, скруглёнными карточками, собственными переключателями и индикаторами состояния. Стекло можно выключить или настроить (*Общие > Стекло панели*).
- **Управление каждым инструментом** — включайте/выключайте GlazeWM, Zebar, Windhawk и тему терминала по отдельности, устанавливайте и удаляйте их через winget прямо из панели.
- **Вкладка «Терминал»** — вставьте любой ASCII-баннер, выберите цветовую схему, цвет ASCII, шрифт, размер, прозрачность и акрил с живым предпросмотром. *Восстановить* возвращает прежний `settings.json` и стандартный логотип.
- **Исключения GlazeWM** — приложения, которые не нужно раскладывать плиткой (игры, лаунчеры, утилиты). Добавляйте по имени процесса или из списка открытых окон.
- **Прозрачность окон** — сделайте любое окно полупрозрачным ползунком в реальном времени и сохраните как правило для приложения; оно применяется автоматически.
- **Виджет терминала на рабочем столе** — необязательная карточка fastfetch на рабочем столе: выбор угла, размер (60–120%) и кнопка закрытия.
- **4 языка** — Русский, English, Português (BR) и Español в панели, меню трея, установщике и деинсталляторе. По умолчанию — язык интерфейса Windows.
- **Обратимо** — конфигурационные файлы, которые заменяет Linuxify, сначала копируются в `backup\`, а деинсталлятор возвращает их. Windows Terminal объединяется, а не перезаписывается: ваши профили и настройки остаются, а всё, что вы измените при включённом режиме Linux, сохраняется в `backup\` перед выключением. Linuxify также добавляет записи автозапуска и одну строку в профиль PowerShell; деинсталлятор их удаляет.

## Требования

- Windows 11 (единственная версия, на которой Linuxify тестируется; Windows 10 может работать, но не проверялась)
- Windows PowerShell 5.1 (встроен)
- [winget](https://learn.microsoft.com/windows/package-manager/winget/) («Установщик приложений») для автоматической установки зависимостей
- Рекомендуется: [JetBrainsMono Nerd Font](https://www.nerdfonts.com/) (установщик может поставить его сам)

## Установка

1. Скачайте `Linuxify-vX.Y.Z.zip` из [Releases](../../releases) и распакуйте в любую папку.
2. Дважды кликните **`Install.cmd`**.
3. Ответьте **y**, чтобы установить/обновить зависимости через winget (GlazeWM, Zebar, Windhawk, fastfetch, Starship и необязательный Nerd Font).

Установщик копирует Linuxify в `%LOCALAPPDATA%\Linuxify`, сохраняет копии конфигов, которые заменяет, записывает конфиги Linuxify, добавляет трей в автозапуск (`HKCU\...\Run`, с `-Boot`, чтобы дождаться панели задач) и запускает его.

Параметры: `install.ps1 -Yes` (без вопросов), `-NoDeps` (без winget), `-NoStart` (не запускать трей).

В архиве есть `Linuxify.exe` (трей, собранный ps2exe). Без него трей запускается из `Linuxify.ps1`.

## Использование

| Действие | Как |
|---|---|
| Переключить режим Linux | Клик по значку в трее или **Ctrl+Alt+L** |
| Открыть панель | Правый клик по значку > *Открыть панель...* |
| Сменить язык | Панель > *Общие* > *Язык* |
| Эффект стекла | Панель > *Общие* > *Стекло панели* (вкл/выкл + интенсивность) |
| Виджет на рабочем столе | Панель > *Общие* > *Терминал на рабочем столе* |
| Удаление | `Uninstall.cmd` или трей > *Удалить всё...* |

### Вкладки панели

- **Общие** — режим Linux, карточки инструментов (состояние, вкл/выкл, установка/удаление), автозапуск, язык, виджет и стекло.
- **Терминал** — ASCII-баннер (сохраняется в `~/.config/fastfetch/logo.txt`), цветовая схема, цвет ASCII, шрифт, прозрачность и акрил.
- **Исключения** — приложения, которые GlazeWM игнорирует. Игры, найденные сканированием, хранятся в правиле `# Jogos (Linuxify)` файла `~/.glzr/glazewm/config.yaml`.
- **Прозрачность** — прозрачность любого окна в реальном времени, сохранённые правила и «применять автоматически».

## Файлы конфигурации

| Файл | Назначение |
|---|---|
| `%LOCALAPPDATA%\Linuxify\panel.json` | Настройки панели (язык, стекло, цвет ASCII, баннер) |
| `%LOCALAPPDATA%\Linuxify\desktop.json` | Виджет рабочего стола (вкл, угол, размер) |
| `%LOCALAPPDATA%\Linuxify\transparency.json` | Правила прозрачности для приложений |
| `%LOCALAPPDATA%\Linuxify\backup\` | Копии конфигурационных файлов, которые заменил Linuxify |
| `~/.glzr/glazewm/config.yaml` | Конфиг GlazeWM (тайлинг, правила, исключения) |
| `~/.config/fastfetch/logo.txt` | Текущий ASCII-баннер (`logo-default.txt` — стандартный) |

Переводы лежат в `lang/*.json` (UTF-8). Новые языки приветствуются — скопируйте `lang/en.json`, переведите значения и откройте PR.

## Удаление

Дважды кликните **`Uninstall.cmd`** (или трей > *Удалить всё...*). Он выключает режим Linux, убирает автозапуск и восстанавливает сохранённые конфиги. `uninstall.ps1 -RemoveApps` также удаляет пакеты winget. Из профиля PowerShell удаляются только строки, добавленные Linuxify. Копии остаются в `%LOCALAPPDATA%\Linuxify\backup`, пока вы их не удалите.

## Решение проблем

- **Ctrl+Alt+L не работает** — сочетание занято другим приложением; используйте значок в трее.
- **Нет значка в трее после входа** — автозапуск около минуты ждёт Explorer и область уведомлений, затем повторяет создание значка. Подробности в `%LOCALAPPDATA%\Linuxify\startup.log`. Если старая установка всё ещё использует прежнюю команду, выключите и снова включите *Запускать с Windows* (следующий запуск тоже переписывает команду). Перезапуск Explorer возвращает значок.
- **Игра или приложение раскладывается плиткой** — добавьте его в *Исключения* или в правило игр.
- **В терминале квадраты вместо значков** — установите Nerd Font и выберите его на вкладке *Терминал*.
- **Нет эффекта стекла** — нужен Windows 11 и включённые эффекты прозрачности в настройках Windows; эффект также можно выключить в *Общие*.

## Changelog

### v0.2.5
- Windows Terminal: при включении режима Linux внешний вид Linux добавляется к вашим *текущим* настройкам, а не копируется поверх файлом времён установки; профили и настройки, изменённые после установки, сохраняются. Всё, что изменено при включённом режиме Linux, сохраняется в `backup\wt-while-on-*.json` перед выключением. Настройки с комментариями не затрагиваются.
- Удаление: восстанавливается только первая копия каждого файла, из профиля PowerShell удаляются только строки самого Linuxify (ваша строка `starship init` больше не стирается), и больше не создаётся скрипт в `%TEMP%` для запуска от имени администратора. `-RemoveApps` удаляет ровно те пакеты, которые ставит установщик. В конце удаляется `backups.txt`.
- Правки профиля и списка копий сохраняют кодировку файла (Windows PowerShell 5.1 писал в ANSI).
- `scripts\New-Release.ps1` собирает zip релиза и `SHA256SUMS`. CI запускает PSScriptAnalyzer и тесты Pester.

### v0.2.4
- Исправлена ошибка при входе в систему `A parameter cannot be found that matches parameter name 'Boot'`. Автозапуск передаёт `-Boot` в `Linuxify.exe` только если exe это поддерживает; иначе запускает `Linuxify.ps1 -Boot` скрыто. Старая команда автозапуска перезаписывается при следующем запуске трея.
- Проверка панели задач использует `FindWindowW` и больше не блокирует значок в трее при сбое.
- Если запуск не удался, сообщение и `%LOCALAPPDATA%\Linuxify\startup.log` указывают, на каком шаге произошла ошибка.

### v0.2.3
- При входе в систему трей ждёт Explorer и область уведомлений (`-Boot` в команде автозапуска) и только потом показывает значок. Если значок не создаётся, попытка повторяется, а ошибка с отметкой времени пишется в `%LOCALAPPDATA%\Linuxify\startup.log`.
- Если Explorer перезапускается, значок в трее возвращается.
- *Запускать с Windows* (установщик, панель и меню трея) записывает новую команду. Уже установленная копия обновляется при следующем запуске трея.
